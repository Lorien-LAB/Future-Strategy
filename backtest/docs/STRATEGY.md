# Calendar-spread v2：当前实现的完整策略说明

## 1. 定义和版本边界

本策略对同一商品的两个交割月份构造价差。主力/次主力是流动性身份，近月/远月是交割顺序；二者不能混用。所有 MR 统计使用 `S = P_near - P_far`；方向 q=+1 表示买近卖远，q=-1 表示卖近买远，同一品种两腿等手数。

本实现来自对旧 `v1-10_Final` 的审查，但已经改变生命周期、账户和部分研究规则。旧原始参考在 `Lorien-LAB/Future-Spread-Trader` 提交 `f7bff2b90087ea85a38449aec878c53e3d0bbe68`。不要把旧业绩数字附在本版本报告上；准确差异见 MIGRATION.md。

## 2. 数据、合约和交易日

行情清洗详见 DATA_CONTRACT.md。默认使用完整实际合约，每个合约/交易日只允许一行。open、close、settlement 各自保留有效性：稍后的 close/settlement 缺失不能删掉有效 open。结算优先于close，允许显式close回退；持仓中没有任何有效估值则终止正式运行并导出此前账本。

品种规格包含乘数m、保证金率r、tick和有效/可知日期。规格未知失败；不会套用通用倍数。市场日历来自输入交易日集合，未自行补中国休市日或星期一至五。数据输入必须预先完成夜盘所属交易日映射。

## 3. 主力、次主力与固定合约段

在D收盘，仅在正有效close、OI>=1000、volume>0、未过期且非交割月保护期的合约中排序。默认主次确认均2天，OI相同按完整合约代码稳定排序。

主力失效立即切至第一；正常替换需要连续确认。次主力排除当前主力和 `previous_main`，变化也需要确认。`previous_main` 在下一次主力更换前保留，不是只排除一天。无活跃合约时结束当前特征段，确认计数清零；不使用未来重新出现的记录回填断档。

Pair发生变化，`PairHistory` 清空旧段的MR/VR/Trend统计，新段从当天close开始累计。旧实际持仓仍保存旧固定合约，不切到新主次价格；D收盘发现pair变化后，发出退出，最早下一执行开盘平旧腿。

## 4. 年度模型与品种选择

测试年Y训练区间 `[Y-train_years-01-01, Y-01-01)`；默认6年。模型在Y年首次信号前冻结。年内不依据未来收益重挑参数。

默认 `training_only`：在 `mr_only_from` 前可以比较MR与Trend两个训练候选，按合格模型的训练CAGR选择；`mr_only_from` 及之后只训练MR。`mr_only` 始终只训练MR。

`fixed_empirical_research` 必须另启用 `allow_retrospective`：Trend为P/Y/M/OI/SC/SA/PP；B/BR/C/CF/JD/LC/LH/MA/NR/PS/UR弃权；其余MR。名单形成于参考过2021–2026业绩之后，因此不能写成2023年事前名单。未来尚无独立验证时，任何配置都不自动成为独立OOS证据。

每个自然训练段按训练截止前实际可见长度统计，包括截至截止时可见的不完整尾段；只对长度>2的段取中位数。MR窗口：`N=max(5,floor(median(length)/2))`，无有效长度回退20。自然段最低数默认 `ceil(5*train_years/6)`，至少1。

## 5. MR 特征、入场与退出

固定pair内信号日D的严格左侧统计：

```text
mu_D = mean(S[D-N:D])
sd_D = population_std(S[D-N:D])
R_D  = S_D - mu_D
Z_D  = R_D / sd_D
```

窗口不含当前信号值。sd=0、残差0或历史不足不产生信号。候选条件为 `abs(Z_D)>sigma_entry`；q=-sign(R_D)。入场之后mu_D与R_D冻结，不能以每日新滚动中心替换。

MR网格是500组：sigma=.1...1.0；T=.1...1.0；S=1.1...1.5。每组在历史训练前缀中使用统一事件引擎重放，至少3笔入场，目标为单品种保证金收益指数的日历CAGR。未完成仓位按截止前估值计入训练净值，不等待未来退出；训练阶段是样本内拟合，可以比较参数，但不能作为独立业绩报告。

默认绝对残差屏障保持原策略意图：

```text
convergence: abs(S_t-mu_D) < T*abs(R_D), confirm 1 close
 divergence: abs(S_t-mu_D) > S*abs(R_D), confirm 3 consecutive closes
```

T/S是相对初始信号残差的比例，不是标准差单位。第一次确认退出后冻结原因，不再继续更新已经结束的交易诊断。

这种规则在残差越过中心且向反方向扩大时仍可能触发divergence，即使实际持仓盈利。因此本版不将该原因命名为现金亏损。`signed_residual` 是另一个显式规则：令a=sign(R_D)*(S_t-mu_D)，a<T*abs(R_D)为有利目标，a>S*abs(R_D)为不利目标，越过中心可以止盈。两个规则不是等价重构。

冷却按全局观察交易日索引保存。若退出在索引i开盘，设置cooldown_until=i+cooldown_days；当close索引小于该值不能产生新信号。默认1意味着退出当天close不能重开、下一观察日close可以再评估。跨年不清空此计数。

## 6. Trend 预热专家

归一化价差 `X=200*(P_near-P_far)/(P_near+P_far)`。通道由当前close之前的L个X构成；尺度是最近L次绝对变化的平均值，包括已观察到的当前close。突破超出 `buffer*scale`；路径效率 `abs(X_t-X_(t-L))/sum(abs(delta X))` 不低于训练门槛。

96组网格：L=10/20/40；效率=.25/.5；buffer=0/.5；hard stop=1.5/2.5；trailing stop=2/3；exit channel=5/10。采用完整历史窗口。退出依次判断方向化亏损硬止损、盈利回撤跟踪止损、完整短通道反向突破、pair边界。

`mr_only_from` 后不产生新的Trend入场，包括上一年末留下的未成交Trend订单；已有Trend实际仓位不被元旦强行清除，仍按其原模型退出。默认2023以后的“MR-only”指新入场族，不声称一定没有跨年的Trend仓位损益。

## 7. 训练质量门

默认训练CAGR>=0，最差年度收益>=-12%。有效段指产生过真实训练入场的去重segment，不要求已闭合。少于 `ceil(10*train_years/6)` 个有效段时，还要求有效得分>=`8*train_years/6`。

MR得分=有效段数×clip(.5+1.5*sigma,.5,2)；Trend为有效段数。选择首先最大化完整训练CAGR，再对赢家执行质量门，不重新在失败赢家之外搜索次优合格参数。完整参数和拒绝原因保留训练审计。

训练收益指数使用连续数量、无组合现金缓冲，属于单品种归一化训练目标，不能冒充实际账户；最终组合使用整数手、保证金占用及现金缓冲。两者目标差异应做稳健性研究，而不是藏起来。

## 8. VR、MRE 和成本覆盖

VR用当前信号及之前的近远月close，最多最近10次对数收益，允许段首至少2次有效收益；采用总体标准差：`VR=std(log returns_near)/std(log returns_far)`。分母0或观察不足无效；近月波动0且远月非零时VR=0有效。

年度阈值由该年度已选MR模型在各自训练期中实际触发的入场特征合并后取 `vr_quantile`（默认P50）。仍OPEN的训练入场也可提供当时已知VR；最大特征日期严格早于该测试年。默认MR要求VR>=阈值；Trend旁路。

下一开盘观察残差 `R_open = P_near_open-P_far_open-mu_D`。MRE要求 `R_open*R_D>0` 且 `abs(R_open)/abs(R_D)>=T`。

成本覆盖估计：

```text
potential_cash_per_lot = abs(R_open)*m
roundtrip_cash_cost    = 2*(P_near_open+P_far_open)*m*b/10000
CER                    = potential_cash_per_lot / roundtrip_cash_cost
```

b默认2bp。完全收敛到中心只是空间估计，不等于条件期望收益，也不等于保证会实现的止盈收益。m和保证金归一分母在比值中抵消。

成本阈值默认网格2/2.5/3/3.5/4/4.5/5。每个部署年，只重放至该年开始前的历史MR流，F25关闭、使用现金扫入、逐年历史模型与2bp费用。至少有交易且最大收盘回撤>=-10%才能参与；CAGR优先，之后回撤较小、调仓少、阈值低。默认门槛不允许比上一年降低。不存在合格门槛则失败，不偷偷使用0或未来最佳阈值。所有网格表现都导出。

## 9. F25 覆盖和更新时钟

信号日单腿 `CL=(2*close-high-low)/(high-low)`，有效零振幅定义0；两腿 `F25=abs(CL_near-CL_far)`。默认all_valid覆盖所有能取得有效OHLC的候选；registry模式按精确起点身份限制覆盖，缺失按显式neutral_keep/reject处理。

F25阈值在信号close时冻结，只取历史信号日更早且上游VR/MRE/CER准入结果已经可知的分数。历史不足80默认中性热身，不直接失败；可配置reject。默认保留F25<=历史P90。

F25分数在候选通过VR/MRE/CER的开盘观察时才加入历史，即使该候选随后被F25本身拒绝也加入。这样不会使用尚未发生的开盘准入结果决定更早的F25样本集合。同一收盘生成的全部信号都冻结在同一历史视图下，处理顺序不会影响同日阈值。

## 10. 实际账户状态与影子状态

`state_policy=shadow` 保留原基础策略占位意图：候选到达可观察的下一开盘后建立虚拟LifeCycle，即使被过滤拒绝，后续入场仍被该虚拟持仓和冷却阻止；虚拟退出按旧固定pair与原信号参数推进，不依赖预先知道的最终退出日期。

`state_policy=actual` 则仅实际成交后建立持仓占位；拒绝交易不会占用虚拟状态。二者都会将真实持仓与待成交订单分开保存。资金不足拒绝也只按对应模式更新。

## 11. 执行时序与可成交假设

默认delayed_open：D收盘信号；D+1开盘观察MRE/CER并决定提交；D+2（更准确说下一观察市场日）开盘按当时可执行双腿价格成交。成交时不重新检查同价MRE/CER，否则会重新引入“先看后同价成交”。等待期间pair变化可取消订单。未提供更细价格时，这是明确的日频研究情景，不是1秒延迟或真实报价模拟。

关闭开盘门的训练/研究可D+1成交。same_open_proxy明确允许D+1观察后同一开盘成交，只供历史口径敏感性，不是可部署证据。

入场某腿下一开盘缺失或侧向不可执行，订单取消，不等到某个未来好价格再补进。退出不可执行则保持EXIT_PENDING和真实持仓，后续可成交开盘再退；仍要有可用日末估值。双腿成交采用原子近似，深度/部分成交/腿间风险未实现。

## 12. 账户、保证金、资金分配与成本

权益E从initial_equity开始。持有Q手时，双腿价格变动损益：`PnL=Q*q*m*[(N_t-F_t)-(N_prev-F_prev)]`。当前占用保证金 `M=Q*m*r_t*(N_mark+F_mark)`。结算改变权益和可用抵押额，不自动改变Q。

cash-sweep在新入场批次触发。先留cash_buffer*E，再扣当前旧仓保证金；新仓目标从等权基准与可用现金扫入中取较大值，并受动态上限限制：1–2品种50%，3品种60%，4品种70%，5及以上min(hard,80%)。实际公式 `min(hard, .5+.1*max(0,n-2))`，hard可配置。

资金不足时，仅从保证金占用最大的旧仓依次减手数；保留每旧仓最低权益比例，费用计入融资需要。非出资旧仓数量保持不变，即使有浮盈。整数新仓不足一手时拒绝；某些新仓无法进入后，会按剩余可成交品种重新计算目标和上限，避免虚增品种数。所有被执行的数量变化都有fill。

预热active_equal是显式的不同政策：新仓事件发生时，把已有及新增仓按等保证金目标求解，旧仓增加/减少都产生交易成本；不是每日因波动自动重平衡。使用cash_sweep可关闭该预热行为。

自然入场/退出及旧仓增减成本统一为 `abs(delta_Q)*m*(P_near_fill+P_far_fill)*bp/10000`，每腿每边。滑点每腿`slippage_ticks*tick`沿不利方向，成交时立即入账。求目标时包含费用与滑点预算；不能在close才扣入场成本。

正常组合保证金不足立即失败并保存状态，不模拟强平恢复，不删除此前亏损。账户可用抵押额不等于券商可提取现金。

## 13. 每日固定顺序

```text
旧仓按当前open盯市 → 执行已确认退出 → 观察/处理新订单
→ 同批资金分配与真实fills/fees → 记录open权益
→ 按settlement或显式close回退盯市 → 记录close权益与保证金
→ D收盘更新主次/特征、旧仓退出条件、新信号
```

旧仓固定模型跨年延续；新信号使用该年的已冻结模型。样本最后仍持有的仓位计入终值并导出OPEN，最后信号和未成交订单也导出，不伪造退出。

## 14. 指标与可复现性

评估基线为开始日前最后一个已观察收盘权益，若没有则initial_equity；首日开盘费用/收益不被归一化掉。CAGR按真实日历跨度365.2425；Sharpe以实际观察市场日close-to-close收益、样本标准差和sqrt(252)计算。最大回撤同时给出close口径和有效open/close事件口径，不等于盘中最大回撤。MAE/MFE以该真实生命周期的累计现金PnL记录，只在存续时更新，不读取退出后路径。

数据、源码、模型、有效配置都保留hash；不同费用可以因资金/整数手改变实际准入数量，这是真实约束下的情景差异，不要求交易数固定。生成报告不预写旧收益，也不以“必须等于旧排行榜”判断正确性。
