# 审查问题与当前处理状态

本表映射已审查旧版本的问题，不代表对所有真实市场情形给出无缺陷认证。原源码基准见MIGRATION.md。以当前实现和测试为依据，而非旧文档描述。

## 未宣称解决的风险

真实成交容量、涨跌停深度、双腿部分成交、夜盘和不同开市时间、官方历史费率/平今规则、强平与追加保证金处理、实盘账户对齐、分钟/逐笔高频、状态断点恢复。日线数据不支持凭空验证这些能力。

此外，固定F25 Q90、训练窗口、屏障、资金政策等仍是开发选择。即使新引擎通过因果测试，也需要冻结方案后使用未参与开发的新数据检验。合成数据的CAGR与Sharpe不得拿来说明商品价差策略可盈利。
